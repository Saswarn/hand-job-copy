# Metrics: AI

## เกณฑ์ (ร่าง)

| ID | เกณฑ์ | เป้า |
|---|---|---|
| AI-1 | ความเร็ว inference บน Pi 5 CPU (640×640) | ≥ 5 fps |
| AI-2 | เวลารวมต่อเฟรม AI (decode + preprocess + infer) | ≤ 200 ms |
| AI-3 | precision ของ `dirt` บน test set | ≥ 0.80 |
| AI-4 | recall ของ `dirt` บน test set | ≥ 0.80 |
| AI-5 | ตรวจเจอ `hand` เมื่อมีมือในกรอบ | ≥ 0.95 |
| AI-6 | ผลสแกนตรงกับคนตัดสิน (สะอาด / ยังมีคราบ) | ≥ 90% ของ 50 ครั้ง |

## วิธีวัด

- **AI-1, AI-2:** [benchmark](../benchmark/) บน Pi จริง
- **AI-3 – AI-5:** รันโมเดลบน test set ที่ผ่าน preprocess แบบเดียวกับ production (binary + letterbox) ที่ IoU 0.5, conf = `dirt_conf`
- **AI-6:** ผู้ใช้จริง 50 ครั้ง คนดูมือใต้ไฟ UV ตัดสินคู่กัน
- บันทึกชื่อไฟล์โมเดล + ค่า `binary_threshold` ที่ใช้ทุกครั้ง
