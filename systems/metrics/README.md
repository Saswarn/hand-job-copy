# Metrics

เกณฑ์วัดผลของแต่ละส่วน ไฟล์ละส่วน: [frontend](frontend.md) · [backend](backend.md) · [docker](docker.md) · [hardware](hardware.md) · [ai](ai.md)

แต่ละไฟล์มี:
1. **เกณฑ์** — ตัวเลขเป้าหมาย (สถานะ **ร่าง** จนกว่าเจ้าของโปรเจกต์ยืนยัน)
2. **วิธีวัด** — ทำซ้ำได้ ใครวัดก็ได้ผลใกล้กัน
3. **ผลการวัด** — เติมแถวใหม่ทุกครั้งที่วัด (ห้ามลบแถวเก่า)

กติกา:
- ตัวเลขด้านความเร็วต้องวัด**บน Pi 5 จริง** — ผลบน Windows / QEMU ใช้ไม่ได้
- ช่อง "version" ใส่ commit hash สั้น
- PR ที่กระทบ metric ต้องแนบแถวผลวัดใน PR body
