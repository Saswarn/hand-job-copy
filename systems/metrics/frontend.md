# Metrics: Frontend

## เกณฑ์ (ร่าง)

| ID | เกณฑ์ | เป้า |
|---|---|---|
| FE-1 | ภาพสดบนหน้าสแกนแสดงได้ลื่น | ≥ 30 fps (บน Pi) |
| FE-2 | กรอบ AI ตรงกับมือ ตอนมือวางนิ่ง | คลาดเคลื่อน ≤ 10 px ที่ 1366×768 |
| FE-3 | แตะจอ → เริ่มสแกน | ≤ 300 ms |
| FE-4 | backend หลุด → ขึ้น "กำลังเชื่อมต่อ…" และต่อกลับเอง | ขึ้นภายใน 2 s, ต่อกลับเองได้ |
| FE-5 | ตัวอักษรอ่านได้จากระยะแขน (~60 cm) | ข้อความหลัก ≥ 32 px, ผ่านการดูจริงโดยคน 3 คน |
| FE-6 | เปิดแอปจนหน้าวิดีโอเล่น | ≤ 5 s |

## วิธีวัด

- **FE-1:** ตัวนับ fps ในหน้า Debug (นับจำนวนเฟรมที่วาดต่อวินาที) เฉลี่ย 60 วินาที
- **FE-2:** วางวัตถุนิ่งที่รู้ตำแหน่ง ถ่ายภาพหน้าจอ วัดระยะขอบกรอบกับขอบวัตถุ
- **FE-3, FE-4, FE-6:** อัดวิดีโอหน้าจอ หรือ `performance.now()` log ใน renderer
- **FE-5:** ดูจริงบนจอ TD1630-3
