การประมวลผลต่อเฟรม

ขั้นวัดอะไรเป้าผลล่าสุด
grabดึง JPEG ดิบจากกล้อง 1 เฟรมได้ fps ตามที่ตั้ง (HW-5)ยังไม่วัด
decodeแตก JPEG แบบย่อขนาดรวมอยู่ใน AI-2ยังไม่วัด
binarycrop + threshold + letterbox 640ยังไม่วัด
inferonnxruntime 1 เฟรมAI-1 ≥ 5 fpsยังไม่วัด
totaldecode + preprocess + inferAI-2 ≤ 200 ms/เฟรมยังไม่วัด

ความแม่นยำ

IDเกณฑ์เป้าวิธีวัดผลล่าสุด
AI-3precision ของ dirt≥ 0.80test set, IoU 0.5ยังไม่วัด
AI-4recall ของ dirt≥ 0.80test set, IoU 0.5ยังไม่วัด
AI-5ตรวจเจอ hand≥ 0.95test setยังไม่วัด
AI-6ผลสแกนตรงกับคนตัดสิน≥ 90%ผู้ใช้จริง 50 ครั้งยังไม่วัด

เกณฑ์ตัดสินผลสแกน

สแกน scan_seconds = 5 วิ dirt conf ≥ dirt_conf = 0.5 ติดกัน ≥ dirt_min_frames = 3 เฟรม → ยังมีคราบ binary binary_threshold = 128
